# Каталог индикаторов

Версия набора правил: **1.0.0** (`pauza/analysis/rules.py`, `RULESET_VERSION`).

Итоговый уровень = максимальный уровень найденных индикаторов, затем применяются комбинации-эскалации. Пользователю показываются не более трёх индикаторов, сначала сильные.

| Код | Уровень | Когда срабатывает | Исключения (не срабатывает) |
|---|---|---|---|
| `OTP_REQUEST` | HIGH | Просьба сообщить/продиктовать/переслать код из СМС, цифры, одноразовый код; «какой код вам пришёл» | Легитимные предупреждения «никому не сообщайте код», «банк никогда не просит код»; промокод, штрих-код, QR-код |
| `CREDENTIAL_REQUEST` | HIGH | Просьба сообщить или ввести пароль, PIN, CVV/CVC, данные или срок действия карты, seed-фразу, приватный ключ | «смените пароль», «придумайте пароль», предупреждения «никому не сообщайте» |
| `REMOTE_ACCESS` | HIGH | AnyDesk, TeamViewer, RustDesk и т.п., «удалённый доступ», демонстрация экрана, установка `.apk` | «мы никогда не просим устанавливать» |
| `URGENT_PAYMENT` | HIGH | Требование перевести/оплатить вместе со срочностью или угрозой (≤ 120 символов между ними); «безопасный/резервный/защищённый счёт» | — |
| `PRIZE_OR_REFUND_FEE` | HIGH | Комиссия, налог, сбор, оплата доставки вместе с выигрышем, призом, компенсацией, возвратом | «комиссия не взимается», «без комиссии» |
| `SUSPICIOUS_DOMAIN` | ELEVATED | Ссылка: IP вместо домена, `user@host`, похожесть на официальный домен, смешение алфавитов, punycode, бренд в чужом домене, сокращатель, подозрительная зона, нестандартный порт, очень глубокие поддомены | Официальные домены из `config/official_domains.json`; кириллические зоны (.рф и др.) не считаются punycode-маскировкой |
| `SECRET_KEEPING` | ELEVATED | «никому не говори», «не сообщайте в банк/родным», «тайна следствия», «не кладите трубку» | «никому не сообщайте код/пароль» (это легитимное предупреждение) |
| `PAYMENT_IRREVERSIBLE` | ELEVATED | Криптовалюта, подарочные карты, Western Union, «через терминал», наличные курьеру — при наличии просьбы заплатить/купить | Упоминание без просьбы об оплате |
| `INVESTMENT_GUARANTEE` | ELEVATED | Гарантированный доход, «без риска», N% в день/неделю, удвоение | «не гарантирует», «риск потери» |
| `IMPERSONATION_CLAIM` | ELEVATED | Служба безопасности, сотрудник банка, ЦБ, ФСБ, МВД, следователь, «мама, это я», «у меня новый номер» | «никому не сообщайте код, даже сотрудникам банка» |
| `IMPERSONATION_CLAIM` (контекстный) | — | Упоминания банка, Госуслуг, ФНС, курьеров, маркетплейсов, поддержки | Учитывается только вместе с другим индикатором |
| `TIME_PRESSURE` | — | «срочно», «в течение 2 часов», «иначе заблокируют» | Учитывается только вместе с другим индикатором |

## Эскалации до HIGH

- сильный признак ссылки (IP, `user@host`, lookalike, смешение алфавитов, бренд в чужом домене) + `IMPERSONATION_CLAIM`
- `PAYMENT_IRREVERSIBLE` + `IMPERSONATION_CLAIM`
- `PAYMENT_IRREVERSIBLE` + `TIME_PRESSURE`
- `PAYMENT_IRREVERSIBLE` + `INVESTMENT_GUARANTEE`
- `SECRET_KEEPING` + `IMPERSONATION_CLAIM`

## Нормализация перед правилами

NFKC, удаление невидимых символов (zero-width, soft hyphen), нижний регистр, `ё → е`, замена латинских двойников на кириллицу внутри слов, где уже есть кириллица («кoд» с латинской o → «код»).
